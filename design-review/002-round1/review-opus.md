## Problems

1. **13-ipad-split-view, 13b-ipad-agent-chat, 13d-ipad-actor-session** — The iPad sidebar has no Intelligence/agents/actor-sessions entries at all, so while you're in Atlas's chat or an actor session nothing in the sidebar is selected and there's no way to reach another agent from it. Fix: add an "Agents" section (pinned agents first, avatar + unread dot) and an "Actors" section (with orange needs-you badge) between Tasks and Connectors; the sidebar should mirror all four iPhone tabs.
2. **05-iphone-agent-chat, 13b-ipad-agent-chat, 06-iphone-actor-session** — Scrolled content runs underneath the floating header and composer without a scroll-edge effect: table rows clash with the "Message Atlas" field; on iPad "lift makes the outer two" sits behind the Atlas capsule; on iPhone the actor transcript overlaps "Add backoff…". Fix: apply `.scrollEdgeEffectStyle(.soft, for: [.top, .bottom])` (or `safeAreaBar`) so text blurs out under glass, and inset content by the header's height.
3. **06-iphone-actor-session, 13d-ipad-actor-session** — The permission card offers four equal-weight buttons in a 2×2 grid; "Deny" is tinted indigo like a positive action; the card is a plain grey fill with no orange "needs you" signal. Fix: one prominent "Allow" (borderedProminent), "Allow for this session" as a menu on Allow or a secondary plain button, "Deny" as a neutral bordered button and "Deny and stop" in a destructive menu item; give the card an orange leading glyph and title "Needs you · Run a command?".
4. **06-iphone-actor-session** — The tab bar remains visible under the actor session's composer, stacking three glass layers at the bottom (spinner, field+stop, tab bar), while Agent chat (05) hides it. Fix: hide the tab bar on every full-page transcript.
5. **13-ipad-split-view (and all iPad shots)** — The floating "Settings" pill overlaps the last sidebar row ("Add Feed" shows as "…ed" behind it). Fix: put Settings in the sidebar's bottom toolbar with a safe-area inset so the list scrolls clear, or move it into the "•••" menu beside the workspace switcher.
6. **13-ipad-split-view (Connectors section)** — Two rows are both titled "Issues" differentiated only by a grey "G"/"L" letter tile, and "Edit" is a navigation row inside the data list. Fix: label "GitHub Issues", "Linear Issues", "GitHub Pull Requests" (or group under service subheaders), use real service marks in their brand-neutral monochrome, and move Edit into the section header as a trailing "Edit" text button like Feeds' disclosure chevron.
7. **07-iphone-tasks, 13c-ipad-tasks, 26-task-detail** — Color carries double meanings: priority flags are indigo (brand accent), orange ("needs you" color) and red ("failed" color), and size chips are a rainbow (Medium blue, Small green, Tiny cyan, Large magenta, Huge red). Fix: Apple Reminders-style priority marks ("!", "!!", "!!!") in a single neutral/orange tone or flags only for high; render size as a neutral grey chip with no color ("S", "M" with a ruler glyph); reserve red for overdue dates and failure.
8. **13c-ipad-tasks, 07-iphone-tasks** — Overdue/today due dates look identical to future ones (Nov 7, Nov 8 overdue; Nov 9 today — all grey). Fix: overdue dates in red, "Today" in orange/indigo semibold, use "Today"/"Yesterday" words instead of dates.
9. **01-iphone-dashboard** — A two-line 34pt greeting with the user's full name plus date occupies 20% of the screen and pushes What's New below the fold. Fix: first name only ("Morning, Jackson") as the large navigation title, date as a `.subheadline` secondary subtitle; tighten the ~80pt gap between the composer chips and What's New to standard section spacing (≈24–32pt).
10. **13-ipad-split-view** — The iPad Dashboard shows an inline "Dashboard" title and then a second large greeting below it; the greeting also differs from iPhone ("Let's get going" vs "Fresh start"). Fix: drop the inline title on Dashboard (or make the greeting the navigation title) and use one deterministic greeting rule across devices.
11. **01-iphone-dashboard, 13-ipad-split-view** — Status glyphs in What's New are a mismatched family: filled orange hand (needs you, ~34pt), hairline grey checkmark with no circle (Done), red xmark.circle (Failed), dashed circle (Working), and a 48pt avatar for Quill. Fix: use one 28pt treatment — either all `.circle.fill` symbols (`hand.raised.circle.fill` orange, `checkmark.circle.fill` green, `xmark.circle.fill` red, ProgressView ring for working) or agent avatar with a small status badge.
12. **13-ipad-split-view** — The "Working" row's title is secondary grey so it looks disabled. Fix: title `.primary`, status line only in `.secondary`; running work is the most live thing on the screen.
13. **05-iphone-agent-chat, 13b-ipad-agent-chat** — The chat header stacks a floating avatar above a separate glass capsule, ~150pt of chrome, and the capsule truncates the description ("plans my week and k…") at caption size. Fix: a standard principal toolbar item with a 28pt avatar beside "Atlas" in `.headline`, drop the description (it lives in agent info) so the header is one glass element.
14. **05-iphone-agent-chat** — The "Cue 'Morning briefing' fired: The…" banner truncates its own message and is a flat grey pill unlike any other card; sender label "● Atlas" is ~11pt tertiary, barely readable. Fix: render cue as a one-line system event `.footnote` secondary ("⚡ Morning briefing · 2 steps ›"), show sender as 20pt avatar + name in `.subheadline.weight(.semibold)` in the agent's color, and drop the hairline divider between turns.

## What works

- The inset-grouped lists on iPhone (Journal, Documents, Settings) have a calm, consistent 44pt row rhythm and sensible relative-date section headers.
- The serif (New York) article reader with good measure and clear heading weights is the most "designed" screen in the set.
- The floating glass tab bar, glass toolbar groups, and the filled-indigo confirm checkmark on sheets feel correctly iOS 27.
- The actor transcript's tool rows ("Edit Connection/Changes.swift ✓ 2s") are compact, scannable and nicely restrained.
- Indigo user bubbles against full-width assistant prose give chats a distinct, web-UI-like character without imitating Messages.

## To reach 9+

1. **Unify the icon system**: one status-glyph family (`.circle.fill` symbols or avatar+badge) wherever state is shown; indigo outlines for navigation; colored tiles only in Settings/agent info; real marks for services instead of letter tiles.
2. **One meaning per color**: indigo = accent/selection, orange = needs-you only, red = failed/overdue, green = connected; make priority and size neutral (Reminders-style "!" marks, grey chips) and keep Deny out of indigo.
3. **Fix transcript chrome**: single compact header, soft scroll-edge effects top and bottom, hide the tab bar in all transcripts, full-width titles on iPad, system events (allowed, cue fired, context rebuilt) as centered footnote lines, and a permission card redesigned as one primary action plus menus, flagged in orange.
4. **Complete the iPad sidebar**: add Agents and Actors sections with selection and badges, rename duplicate connectors, move Edit into a header, and dock Settings properly so it never overlaps the list.
5. **Make every screen state one main action and one title style**: Dashboard (short greeting, What's New above the fold), Journal (write today), Feeds (article river), Task detail (large editable title), and a single title rule — large for tab roots, centered inline for pushed screens.
