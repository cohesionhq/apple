## What works

- Agent color is the same object everywhere: Atlas blue, Scout green, Quill purple, and Relay teal on the dashboard, the agent list, the sidebar, and task assignees.
- What’s New already has a readable status language: filled orange hand, gray check, red x, then a quiet subtitle (`01-iphone-dashboard-light`, `13-ipad-split-view-light`).
- The article’s type hierarchy is the one to copy: large title, quiet byline, indigo source, bold section heads, a comfortable iPhone measure (`34-article-light`).
- Decisions are visually settled where the chrome lets them be: Allow filled, Deny gray (`06-iphone-actor-session-light`, `13d-ipad-actor-session-light`), and the A/B/C slot card with one selected row (`13b-ipad-agent-chat-light`).
- Settings is a finished grouped screen: section labels, trailing On/Off, and symbol tiles at one size (`14-settings-light`).

## To reach 9+

1. **Make every bar actually cover its content.** One inset rule and a real material, applied to the tab bar, composer, nav bar, and sidebar footer. That is the largest jump available for Consistency, Native, and Spacing.
2. **Design the iPad column.** A 680pt measure, a columned task grid, a sidebar footer that fits, and Feeds in the sidebar. That is the largest jump for Typography, Hierarchy, and Native.
3. **Freeze the color and status set into a few components** and use only those: secondary directory icons, indigo for selection and primary buttons, the four status circles, orange for needs-you, red for failed and destructive, green for connected. That lifts Color and Iconography.
4. **Give each screen one primary action and one chrome rule.** Journal gets +, agent info gets Message, the task sheet gets a complete control, the actor prompt gets a pinned Allow/Deny, sheets get one dismiss pattern. That lifts Hierarchy and Consistency.
5. **Put the work that needs the user first.** Intelligence opens with the waiting actor, the dashboard keeps Needs you above the fold and clear of the tab bar, and Workspace shows counts so it stops being a second settings list. That lifts Hierarchy and Overall.
