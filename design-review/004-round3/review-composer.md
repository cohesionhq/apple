## Problems

1. **`01-iphone-dashboard-light`, `02-iphone-intelligence-light`, `03-iphone-workspace-light`, `05-iphone-agent-chat-light`, `12-iphone-contact-light`.** Scroll content is still legible under the floating tab bar and composers: the dashboard’s “Working” row and Quill row, Intelligence’s second actor row, Workspace’s “Launch this week” / connector rows, the chat table and follow-up line, and the contact Notes card all collide with bottom chrome. **Fix:** apply one `safeAreaInset` (tab bar + 12–16pt) on every scrolling root; use `.scrollEdgeEffectStyle(.soft, for: .bottom)` plus regular material on the tab bar so text underneath is not readable; pin the chat composer the same way Messages does.

2. **`02-iphone-intelligence-light`, `01-iphone-dashboard-light`, `13-ipad-split-view-light`.** The highest-urgency state is still below the fold. Actors with “Needs you” sit last on Intelligence and compete with the tab bar; the dashboard sorts statuses but Working only appears once you scroll past What's New. **Fix:** when any actor needs you, make **Actors** (or a single “Needs you” card) the first section on Intelligence, above pinned agents; on the dashboard, pin incomplete needs-you rows above Done/Failed/Working and keep them clear of the tab inset from problem 1.

3. **`13-ipad-split-view-light`, `13b-ipad-agent-chat-light`, `13c-ipad-tasks-light`, `13d-ipad-actor-session-light`.** The detail column is still a stretched iPhone layout: greeting and composer float in a sea of white, chat paragraphs span the full 13″ width, and task flags sit far right with weak pairing to titles. The sidebar bottom still stacks a selected actor pill against navigation chrome. **Fix:** cap transcript, composer, greeting, and article-like content at ~640–680pt leading-aligned; use a task grid with fixed trailing columns (due, assignee, list, flag); one sidebar footer slot—session title + orange “Needs you” caption or toolbar Settings, not both overlapping.

4. **`06-iphone-actor-session-light`, `13d-ipad-actor-session-light`.** The permission moment is improved (orange stroke, Allow primary) but the screen still fights for attention: title truncates before “reconnect”, repo caption “apple” is cryptic, code blocks clip (`Duration`, `attempt`, `xcodebuild` mid-token), and the bottom stacks Follow up, an ambiguous progress ring, red stop, and (on iPhone) system tab bar. **Fix:** hide tab bar on this push; pin Allow / Deny / … above the keyboard in a bottom accessory; show Follow up only after resolution; replace the idle ring with a labeled Stop while running; one `CodeBlock` style—`.footnote` monospaced, 16pt padding, horizontal scroll; nav title two lines `.headline` + `.caption` secondary repo name.

5. **`01-iphone-dashboard-light`, `03-iphone-workspace-light`, `04-iphone-feeds-light`, `13-ipad-split-view-light`.** iPhone tabs and iPad sidebar still tell different stories: four tabs on phone vs Dashboard + library rows + agents on iPad; Feeds absent from sidebar; Settings gear on Intelligence/Workspace/Feeds but not on the dashboard tab in `01`. **Fix:** align primary navigation (Dashboard, Intelligence/agents hub, Workspace, Feeds) on both platforms; put Settings only in a toolbar control present on every root, including Dashboard.

6. **`26-task-detail-light`, `07-iphone-tasks-light`, `13c-ipad-tasks-light`.** Task detail reads as a settings form, not the object from the list: generic “Task” title, gray inactive check beside working dismiss, duplicate “Set Size” / empty size, due as a toggle instead of “Nov 15”, and no leading complete control matching the list. Metadata on list rows is a run of same-weight chips where “waiting” looks like a tag. **Fix:** sheet title = task name `.title3`; leading circle completes like the list; due row shows the date in `.body`, red when overdue; empty fields use “Add size” / “Add tag” in secondary `.body`; second line order: date → assignee → list → tag capsules; “waiting” as orange-tinted `.caption` capsule, distinct from grey tags.

7. **`14-settings-light`, `17-agent-info-light`, `26-task-detail-light`, `12-iphone-contact-light`.** Sheet chrome varies: checkmark-only dismiss on Settings and agent info, X + disabled check on task, circular indigo back on contact. Destructive rows (Unpair, Delete Agent) read like broken navigation rows. **Fix:** browse sheets = nav title + trailing X; edit sheets = X plus indigo check only when dirty; destructive actions centered `.body` red in an isolated section, no chevron.

8. **`05-iphone-agent-chat-light`, `13b-ipad-agent-chat-light`.** Chat typography and markup lack a system: cue row truncates (“The…”, “2 steps” orphaned), tables sit naked without a container, links (`hellocohesion.io`) differ from article indigo links, duplicate “Atlas” attribution, Done checks in a checklist use purple while dashboard Done is grey. **Fix:** cue as full `.subheadline` secondary with trailing step count; tables inside the same rounded scroll container as code blocks; all `cohesion://` and external links indigo `.body`; one Done glyph (secondary `checkmark.circle`) app-wide; nav = avatar + name on material, bio only on info sheet.

9. **`01-iphone-dashboard-light`, `02-iphone-intelligence-light`, `03-iphone-workspace-light`, `14-settings-light`, `05-iphone-agent-chat-light`.** Indigo is doing too many jobs—tab selection, directory icons, Teams link, user bubbles, Allow, iPad selection pills—so selection and “tap me” blur together. Settings rainbow tiles introduce unrelated hues (orange profile, pink memories) beside semantic agent colors. **Fix:** hierarchical `.secondary` for library/connector/feed rows; reserve indigo for selection, links, and filled primaries; keep Settings icons neutral grey or agent-adjacent only where they denote entity type; document the five functional colors in `docs/design.md` and audit outliers.

10. **`03-iphone-workspace-light`.** The Workspace tab is still a flat launcher: no section header on the first card, identical indigo icons and chevrons, Inbox and All sharing the tray symbol, no counts or needs-you signal. **Fix:** label the first group “Library”; secondary icons; Inbox trailing count in `.subheadline`, orange when any task needs you; differentiate All (`rectangle.stack`) from Inbox (`tray`); Today subtitle “N due”.

11. **`04-iphone-feeds-light`, `08-iphone-journal-light`, `10-iphone-documents-light`, `44-extensions-light`.** Sibling lists use different chrome: Feeds large title vs Journal/Documents inline centered vs Extensions large title; Journal has no search/+; feed unread counts are grey like timestamps. **Fix:** root browsable lists share large title + trailing +; pushed lists use inline title; unread = indigo capsule `.caption` bold; give Journal search when the dataset grows.

13. **`50-widget-agents-small-light`, `51-widget-agents-medium-light`, `52-widget-agents-large-light`.** Home-screen agents widgets break product language: small widget says “Need you” (grammar) with a lone “3” and no app name; medium/large show “Needs you” in **grey** while orange means needs-you everywhere else. 20. **`06-iphone-actor-session-light`.** Activity lines (“Write”, “Bash”) and durations are quieter than body prose, so the timeline reads as undifferentiated paragraphs. **Fix:** tool name `.caption` uppercase tracking in tertiary; path `.footnote` monospaced; duration trailing `.caption2` secondary; optional thin divider between beats.

## What works

- **Semantic status in What’s New and lists** — orange hand, grey check, red x, then quiet time subtitle reads instantly (`01-iphone-dashboard-light`, `13-ipad-split-view-light`).
- **Agent color as identity** — Atlas, Scout, Quill, Relay, Ledger discs match across dashboard, Intelligence, sidebar, and assignee chips.
- **Article reader** — serif title, indigo source link, comfortable measure, and section heads set the type standard to spread elsewhere (`34-article-light`).
- **Permission decision layout (round 3)** — orange-framed card, filled Allow, bordered Deny, optional note (`06-iphone-actor-session-light`, `13d-ipad-actor-session-light`).
- **Live Activity summary** — header counts, orange “Needs you” row, timers for working sessions, and segmented progress bar feel purposeful (`57-live-activity-lockscreen-light`, `58-live-activity-expanded-light`).

## To reach 9+

1. **Enforce scroll insets and materials on every bar** — tab bar, composers, and nav bars must opaque-out content beneath them; actor session hides the tab bar. Biggest lift for Native, Consistency, and Spacing.
2. **Design the iPad detail column as its own layout** — max readable width, task grid, sidebar footer that doesn’t overlap, Feeds in the sidebar. Biggest lift for Typography, Hierarchy, and Overall.
3. **Ship widget/Live Activity as strict exports of in-app semantics** — orange “Needs you”, red overdue, green connected, red failed, with no grey status text or orange used for ordinary dates. Lifts Color, Consistency, and Iconography off-device.
4. **Freeze navigation and sheet grammar** — one title style per presentation level, one dismiss pattern, one primary action per screen (Message on agent info, complete on task sheet, pinned Allow on actor). Lifts Hierarchy and Consistency.
5. **Prioritize “needs you” in information architecture** — Intelligence and dashboard open with waiting work; Workspace shows counts. Lifts Hierarchy and Overall without new features.
