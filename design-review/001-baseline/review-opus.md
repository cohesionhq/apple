## What works

- Workspace and Feeds lists: one outline SF Symbol family in indigo, clean inset grouped sections, trailing counts — this is the template every list should follow.
- The article reader's serif typography with clear headings and comfortable measure is the best personality moment in the app.
- Compact tool-call rows in actor sessions ("Edit Connection/Changes.swift ✓ 2s") are dense, scannable and professional.
- Settings uses colored squircle icons and clear Server / This iPhone sectioning with a destructive Unpair row set apart.
- The indigo user bubbles vs. unbubbled agent replies give chat a calm, document-like reading flow that matches the refined web feel.

## To reach 9+

1. **Fix the information architecture on iPad and the Dashboard**: add Agents and Actors to the iPad sidebar, and rebuild the Dashboard around a pinned "Needs you" section (orange) above a grouped What's New, with a leading large title and first-name greeting.
2. **One meaning per color everywhere**: orange = needs you only (badge included), red = failed only, green = connected only, indigo = accent/links only; make size chips monochrome and priority flags neutral except Urgent.
3. **Unify navigation chrome**: large titles on every root/list, inline on details; system nav bar with scroll edge effect everywhere (no opaque bars, no content bleeding under); hide the tab bar in every conversation; one glass title capsule with inline avatar for agent and actor headers.
4. **Rebuild the conversation surfaces' controls**: two-button permission card (Allow / Deny + menu), single-row composer with stop+progress combined, correct bottom insets, rendered Markdown task lists, 680pt reading measure on iPad, system decisions as status lines not user bubbles.
5. **Iconography and polish sweep**: SF Symbols instead of status emoji, real or colored extension tiles, fix the gear glyph and separator insets, strip Markdown from previews, keep the sidebar Settings capsule off the last row, give agent info an identity header — and re-shoot 17 in light mode.
