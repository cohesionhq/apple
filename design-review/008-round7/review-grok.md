## What works

- Agent replies as full-width prose and the person as an indigo bubble, with headings, numbered lists, and links that read as a document (`05-iphone-agent-chat-light`, `13b-ipad-agent-chat-light`).
- The orange hand for “Needs you,” carried from What’s New through the actor row into the permission card, where Allow is the single primary action (`01-iphone-dashboard-light`, `06-iphone-actor-session-light`, `57-live-activity-lockscreen-light`).
- The article: large title, quiet byline, a readable measure, inline code, and a distinct code block (`34-article-light`).
- The Liquid Glass tab bar, the unread badge, and inset grouped lists on Intelligence, Workspace, Feeds, and Settings.
- Agent color discs, from the pinned grid through the sidebar into the chat title, so Atlas stays blue and Quill stays purple (`02-iphone-intelligence-light`, `05-iphone-agent-chat-light`, `13-ipad-split-view-light`).

## To reach 9+

1. Redesign the iPad detail pane as its own layout: navigation bar, two-column dashboard, columnar tasks, a 680pt measure for chat and actor transcripts, and sidebar content that clears the home indicator. This is the change that moves Hierarchy, Spacing, and Native together.
2. Write a two-style metadata rule and use it everywhere a fact is scanned: `.subheadline` secondary for dates, assignees, versions, and journal previews; `.caption` only for true annotations. Overdue stays red. This is the Typography move, and it fixes the iPad task rows, documents, inbox chips, and the task widgets in one pass.
3. Lock the color language and apply it to widgets and settings: orange is needs-you (widget label included), red is failed or destructive, green is connected, and settings and agent-info tiles are neutral. The Live Activity and the dashboard use one check color for done. This is the Color move.
4. Rebuild the three agent widgets as a family that fills the size: no cropped overlap, no empty middle, no duplicated hero, “Needs you” in orange, and the large widget as a list only. Then let the task widgets show as many rows as the size fits, with the extra-large as two columns. This is the Spacing move.
5. One chrome and one identity mark. Large titles on tab roots, inline titles on pushes, sheets titled by the object, code and tables kept inside their containers, and a single disc avatar for agents and extensions. This is the Consistency move, and it removes the clipped code, the table under the composer, and the gray extension tiles.
