## What works

- The actor permission card (`06-iphone-actor-session-light.png`, `13d-ipad-actor-session-light.png`) is the one place with a single decision: an orange border, the hand, the command in its own block, Allow as the filled primary, Deny as the secondary pill.
- The article reader (`34-article-light.png`) has a real type scale: large title, byline, a comfortable measure, headings that break the body, and a code block that is clearly a block.
- All tasks on iPad (`13c-ipad-tasks-light.png`) is a professional table: checkbox, title, overdue dates in red, assignee, flag, aligned across the pane.
- The chrome is actually iOS 27: a floating glass tab bar with a badge, toolbar buttons grouped in capsules, inset grouped lists, and sheets that close with a round button.
- Session state uses the same marks in What’s New and the Live Activity: orange hand, blue dotted ring, check, red failure (`13-ipad-split-view-light.png`, `57-live-activity-lockscreen-light.png`).

## To reach 9+

1. Lock the color language. Agent discs may not be orange, red, or green. Settings tiles go neutral. Priority stops using amber and red flags. Indigo is the selected tab, the primary button, and links. Orange is only “needs you”, red only overdue and failed, green only connected or allowed. This is the change that moves Color.
2. One task component and one needs-you count, used on the dashboard, the inbox, the iPad table, and every widget size. Same words for dates, same columns when there is width, and the small agents widget cannot say 3 while the large says 2. This is the change that moves Consistency.
3. Design the canvas that is actually on screen. Agent widgets fill their width with named people. Task widgets show as many rows as fit, and extra-large adds the iPad’s columns. Chat and actor transcripts sit in a ~680pt column, in scroll order, under a bar they clear. This is the change that moves Spacing.
4. Put one action first on the home surfaces. Dashboard opens on Needs you, with the composer pinned. Intelligence shows status on the pinned agents and lifts the waiting actor. Workspace shows counts and the work, in label-colored symbols. The phone adopts the iPad’s status row. This is the change that moves Hierarchy.
5. A type ramp for everything that is not the title, and a ban on clipped lines. Dates, sources, tags, and “2m ago” are footnote or subheadline secondary. Code wraps or scrolls inside its block. Tables scroll. Content insets clear the tab bar, the composer, and the navigation bar. This is the change that moves Typography.
